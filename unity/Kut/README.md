# KUT Unity project

**Open this folder in Unity Hub** with **2022.3 LTS** (macOS Monterey 12+ / Intel MacBook Air 2015 supported).

1. Repo root: `./tools/sync-core-to-unity.sh`
2. Hub → Add → this folder
3. Editor menu **KUT → Create Main Scene And Open**
4. Play

Details: [`../../docs/unity-setup.md`](../../docs/unity-setup.md)
